## Original_data 資料集

- 此資料集為原始股票資料
- 資料年份範圍：非全部包含 99 年至 113 年（西元2010-2024年）
- 檔案命名格式：`"股票代號"_2010_2024.csv`（例如：`2330_2010_2024.csv`）

## 資料處理建議

1. **資料選取原則**：
   - 建議優先選取從 99 年（西元2010年）開始就有完整資料的公司
   - 避免使用資料量過少的公司數據，可能導致訓練效果不佳

2. **演算法適應處理**：
   - 請根據每個演算法的具體需求進行資料前處理
   - 需檢查並處理以下問題：
     - 不同公司的資料時間範圍不一致
     - 資料缺失值處理
     - 特徵工程與標準化

3. **檔案結構範例**：
```
    Original_data/
    ├── 1101-2010-2024.csv
    ├── 2330-2010-2024.csv
    ├── 3008-2010-2024.csv
    └── ...
```
